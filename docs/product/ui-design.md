# UI 界面设计

## 目的

定义"资料收藏夹"的界面布局、导航方式和交互模式。

## 读者

参与前端开发和 UI 设计的人。

## 整体布局

左侧边栏（一级导航）+ 右侧内容区：

```text
┌──────────┬──────────────────────────────────┐
│          │  🔍 搜索框                        │
│  URL     ├──────────────────────────────────┤
│  笔记    │                                  │
│  图片    │         内容区域                  │
│  标签管理 │                                  │
│          │                                  │
├──────────┤                                  │
│  设置    │                                  │
└──────────┴──────────────────────────────────┘
```

## 侧边栏

- **纯一级导航**：URL、笔记、图片、标签管理、设置
- 不展示子级分组，子功能在内容区域内部实现
- 支持折叠/展开，折叠后只显示图标

折叠状态：

```text
┌──┬─────────────────────────────────────────┐
│📑│                                         │
│📝│         内容区域                         │
│🖼│                                         │
│🏷│                                         │
├──┤                                         │
│⚙│                                         │
└──┴─────────────────────────────────────────┘
```

## 搜索

- 每个模块（URL/笔记/图片）有独立搜索框，固定在内容区顶部
- 切换模块时搜索状态独立保留
- 搜索范围详见 [功能需求 § 搜索能力](./requirements.md#搜索能力)

## 各模块内容区布局

### URL 模块 — 双栏

左侧列表 + 右侧详情。

**默认状态：按站点分组折叠**

```text
🔍 [搜索...]  [站点筛选 ▼] [存活检测]
┌──────────────────────┬─────────────────────────┐
│ ▼ GitHub (3)         │  标题: golang/go         │
│   ├ 📌 golang/go     │  URL: github.com/go...  │
│   ├ 📌 react         │  站点: GitHub           │
│   └ 📌 vscode        │  Tags: #Go #开源         │
│ ▶ React 官网 (5)     │  描述: Go 语言主仓库      │
│ ▼ MDN (2)            │  添加时间: 2026-06-22    │
│   ├ 📌 CSS Grid 指南  │                         │
│   └ 📌 Fetch API     │                         │
└──────────────────────┴─────────────────────────┘
```

- 站点作为可展开/折叠的分组头，旁边显示 URL 数量
- 点击具体 URL 时右侧展示详情

**搜索状态：平铺展示**

搜索时打破分组，结果平铺显示，每条标注所属站点：

```text
🔍 [go...]  [站点筛选 ▼] [存活检测]
┌──────────────────────┬─────────────────────────┐
│ 📌 golang/go         │  标题: golang/go         │
│    github.com  #Go   │  URL: github.com/go...  │
│ 📌 Go by Example    │  站点: GitHub           │
│    gobyexample.com   │  Tags: #Go #开源         │
│ ...                  │  ...                    │
└──────────────────────┴─────────────────────────┘
```

搜索清空后恢复分组视图。

子功能（站点筛选、失效链接过滤等）作为内容区顶部的筛选控件实现。

### 笔记模块 — 双栏

左侧标题列表 + 右侧 Markdown 编辑/预览：

```text
🔍 [搜索...]
┌──────────────────┬─────────────────────────┐
│ 📝 学习笔记      │  # 学习笔记              │
│ 📝 会议记录      │                         │
│ 📝 想法          │  今天学了 Go 的接口...   │
│    ...           │                         │
│                  │  [编辑] [预览]           │
└──────────────────┴─────────────────────────┘
```

### 图片模块 — 网格

缩略图网格展示：

```text
🔍 [搜索...]  [文件夹筛选 ▼] [扫描]
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│      │ │      │ │      │ │      │
│  🖼  │ │  🖼  │ │  🖼  │ │  🖼  │
│      │ │      │ │      │ │      │
│photo1│ │photo2│ │photo3│ │photo4│
│#风景  │ │#美食  │ │#旅行  │ │#日落  │
└──────┘ └──────┘ └──────┘ └──────┘
```

点击图片可展开详情（标签编辑、原图预览、文件信息等）。

子功能（文件夹筛选、手动扫描触发）作为内容区顶部控件实现。

### 标签管理模块

URL 标签和图片标签分 Tab 管理：

```text
[URL 标签]  [图片标签]
🔍 [搜索标签...]
─────────────────────────────────────
前端::React        (12 个关联)  [重命名] [合并] [删除]
前端::Vue          (8 个关联)   [重命名] [合并] [删除]
工具::编辑器       (5 个关联)   [重命名] [合并] [删除]
...
```
