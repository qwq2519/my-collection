## 备注

- 媒体网格区域（展示图片缩略图）局部用 `bg-white` 纯白底，避免暖黄底色影响照片色彩准确性
- 主题通过 CSS 变量实现，切换只改 `<html data-theme="xxx">`，不需要重新加载
- 主题注册中心代码设计见 `frontend/src/themes/`（搭建前端时创建）
