# 前端 UI/UX 设计规范

目标：**简洁、克制、信息密度高、工具感强**。

参考产品：Linear、Notion、Raycast、Things 3、Obsidian。

---

## 核心原则

1. **内容是主角** — UI 框架（侧边栏、搜索栏、按钮）应尽可能"隐形"，不争夺注意力
2. **做减法** — 能去掉的视觉元素就去掉，留下的每一个都有功能意义
3. **一致性** — 间距、字号、颜色、圆角在全局保持统一，不逐个组件微调

---

## 颜色

只用一个强调色，其余用灰阶。

| 用途 | 色彩策略 |
|------|---------|
| 背景 | 白 / 极浅灰 |
| 正文 | 深灰（不用纯黑） |
| 次要文字 | 中灰（`text-muted-foreground`） |
| 占位符 | 浅灰 |
| 强调色 | 1 个（按钮、选中态、链接），使用 shadcn `primary` |
| 危险操作 | 红色系（删除确认） |
| 边框 | 极浅灰（shadcn `border`，几乎看不见但能感知） |

**禁止**：每个模块分配不同颜色、渐变背景、多彩标签、大面积饱和色块。

---

## 字体与层级

用**字重和灰度**区分层级，不靠字号跨度。字号集中在 12-16px。

| 场景 | 大小 | Tailwind | 字重 |
|------|------|---------|------|
| 列表项标题 / 正文 | 14px | `text-sm` | `font-medium` / `font-normal` |
| 次要信息（时间、域名） | 12px | `text-xs` | `font-normal` + `text-muted-foreground` |
| 区域标题 | 16px | `text-base` | `font-semibold` |
| 页面大标题（极少用） | 18px | `text-lg` | `font-semibold` |

---

## 间距

全局只用 3 个间距档位：

| 档位 | 值 | Tailwind | 场景 |
|------|-----|---------|------|
| 紧凑 | 4-8px | `gap-1`, `gap-2` | 列表项内部、图标与文字 |
| 常规 | 12-16px | `gap-3`, `gap-4` | 区块内部元素间 |
| 宽松 | 24-32px | `gap-6`, `gap-8` | 区块之间、表单分组之间 |

---

## 边框与阴影

边框优于阴影。阴影只用在浮层上。

| 元素 | 样式 |
|------|------|
| 区域分割 | `border-r` / `border-b` |
| 列表项之间 | 无边框（靠间距），或 `border-b` |
| 下拉菜单、弹窗 | `shadow-md`（仅浮层） |
| 卡片 | 通常不需要，如必须则 `border` 无阴影 |

---

## 列表

列表项不用卡片包裹，用 hover 反馈区分交互区域。
选中态使用 `bg-muted`，不用左侧色条、高亮边框。

```tsx
<div className="px-3 py-2 cursor-pointer rounded-md hover:bg-muted">
  <div className="text-sm font-medium">标题</div>
  <div className="text-xs text-muted-foreground">次要信息</div>
</div>
```

---

## 标签

所有标签统一样式，不按内容分配颜色：

```tsx
<Badge variant="secondary">标签名</Badge>
```

---

## 图标

- lucide-react 线性图标（outline），不用填充图标
- 大小：正文旁 `size={16}`，按钮内 `size={14}`
- 只在需要视觉锚点的地方使用（侧边栏导航、操作按钮），不给每行文字加图标

---

## 动效

桌面工具追求即时响应，动效要快且微妙：

| 交互 | 时长 |
|------|------|
| hover 变色 | 150ms |
| 折叠/展开 | 150-200ms |
| 弹窗出现 | 150ms |
| 页面切换 | 0ms（直接切换） |

禁止 300ms+ 动画、元素进场动画、hover 放大效果。

---

## 组件规范

### 侧边栏

- 宽度 220px，折叠 48px
- 浅灰底 + `border-r`
- 选中态 `bg-muted font-medium`

### 详情区

- 不加外边框，靠留白分隔
- 信息分层：标题 → 次要信息 → 正文 → 标签 → 分割线 → 元信息

### 表单

- 垂直排列，标签在上方
- 必填用 `*`，错误 `text-xs text-destructive`
- 按钮右对齐：主操作 `Button`，取消 `Button variant="ghost"`

### 空状态

- 居中灰色图标 + 一行说明
- 不用插画或 emoji

---

## 反模式清单

| 禁止 | 正确做法 |
|------|---------|
| 卡片包裹列表项 | 无框列表 + hover 反馈 |
| 多彩标签 | 统一 `Badge variant="secondary"` |
| 字号跨度超 12-18px | 字重 + 灰度区分 |
| hover 放大 | hover 背景变色 |
| 慢动画 (300ms+) | 150ms 过渡 |
| 大留白 | 紧凑信息密度 |
| 渐变/发光/装饰线 | 纯色 + 极浅灰边框 |
| 每行加图标 | 仅导航和操作按钮 |
| 填充图标 | 线性图标 |
