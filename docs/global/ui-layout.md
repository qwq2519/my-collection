# 整体布局

## 布局结构

左侧边栏（一级导航）+ 右侧内容区：

```text
┌──────────┬──────────────────────────────────┐
│          │  🔍 搜索框                        │
│  URL     ├──────────────────────────────────┤
│  笔记    │                                  │
│  媒体    │         内容区域                  │
│  标签管理 │                                  │
│          │                                  │
├──────────┤                                  │
│  设置    │                                  │
└──────────┴──────────────────────────────────┘
```

## 侧边栏

- **纯一级导航**：URL、笔记、媒体、标签管理、设置
- 不展示子级分组，子功能在内容区域内部实现
- 支持折叠/展开，折叠后只显示图标

折叠状态：

```text
┌──┬─────────────────────────────────────────┐
│📑│                                         │
│📝│         内容区域                         │
│🖼│                                         │
│🏷│                                         │
├──┤                                         │
│⚙│                                         │
└──┴─────────────────────────────────────────┘
```

## 搜索与筛选

- 每个模块（URL/笔记/媒体）有独立搜索框，固定在内容区顶部
- 切换模块时搜索状态独立保留
- 搜索框输入和结构化筛选同时生效时取**交集（AND）**

**搜索框（文本搜索）**：用户输入关键词，匹配 text 类型字段：

| 模块 | 搜索框匹配字段 |
|------|--------------|
| URL（站点 + 书签） | title + description + 域名（分词匹配） |
| 笔记 | title + 正文全文 |
| 媒体 | 文件名 |

**结构化筛选**：通过下拉/多选控件筛选，走 keyword 精确匹配：

| 模块 | 筛选方式 |
|------|---------|
| URL | 标签多选（AND 语义）、站点筛选 |
| 媒体 | 标签多选（AND 语义）、文件夹筛选、类型筛选（图片/视频） |

详细索引策略见 [数据结构 - 搜索与筛选策略](./data-structures.md#搜索与筛选策略)。

## 列表排序

默认排序逻辑：按 **`updated_at` 降序**（最近修改的排在前面）。各模块通用，不引入额外的 `accessed_at` 字段。

**URL 模块特殊规则**：站点的 `updated_at` 会随书签更新而更新（书签增删改时同步更新所属站点的 `updated_at`），因此站点列表按 `updated_at` 排序即为按最新书签活动排序。

## 列表渲染

**分页按需加载**：前端不一次性加载全量数据，而是分页向后端请求。滚动到列表底部时自动加载下一页（无限滚动）。结合虚拟滚动，只渲染可视区域内的列表项。

| 参数 | 说明 |
|------|------|
| 每页条数 | 后端默认 50 条，前端可指定 |
| 排序 | 由后端完成，固定 `updated_at` 降序 |
| 搜索/筛选 | 条件变更时重置分页，从第一页重新加载 |

**URL 模块分页单位**：分页单位为**站点**（每页 50 个站点），展开站点时全量加载该站点下的所有书签（仅列表摘要信息：title、domain、tags），不做站点内分页。点击具体书签时再加载完整详情（description、cover、attachments、status 等）。
