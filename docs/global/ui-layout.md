# 整体布局

## 布局结构

左侧边栏（一级导航）+ 右侧内容区：

```text
┌──────────┬──────────────────────────────────┐
│          │  🔍 搜索框                        │
│  URL     ├──────────────────────────────────┤
│  笔记    │                                  │
│  图片    │         内容区域                  │
│  标签管理 │                                  │
│          │                                  │
├──────────┤                                  │
│  设置    │                                  │
└──────────┴──────────────────────────────────┘
```

## 侧边栏

- **纯一级导航**：URL、笔记、图片、标签管理、设置
- 不展示子级分组，子功能在内容区域内部实现
- 支持折叠/展开，折叠后只显示图标

折叠状态：

```text
┌──┬─────────────────────────────────────────┐
│📑│                                         │
│📝│         内容区域                         │
│🖼│                                         │
│🏷│                                         │
├──┤                                         │
│⚙│                                         │
└──┴─────────────────────────────────────────┘
```

## 搜索

- 每个模块（URL/笔记/图片）有独立搜索框，固定在内容区顶部
- 切换模块时搜索状态独立保留
- 搜索范围：

| 模块 | 可搜索字段 | 最重要 |
|------|-----------|--------|
| URL | 域名、title、description、tag | tag |
| 笔记 | title、内容全文 | 全文 |
| 图片 | 文件名、tag | tag |

## 列表排序

默认排序逻辑：**最近使用时间 > 创建时间**（最近操作过的排在前面）。

## 列表渲染

数据量大时采用虚拟滚动，只渲染可视区域内的列表项。

## 应用设置

- 数据目录：默认 `persist/` 路径
- 图片文件夹列表管理入口（添加/移除）
- 主题与外观偏好：后续考虑
