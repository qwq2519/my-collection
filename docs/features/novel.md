# 小说管理（暂不实现）

本地小说书架 + 阅读器，管理和阅读本地小说文件。

## 需求

### 核心能力

| 能力 | 说明 |
|------|------|
| 导入 | 支持 TXT、EPUB，单本导入（非文件夹扫描） |
| 元信息 | 书名、作者、封面、来源链接、标签、阅读状态 |
| 章节解析 | TXT 按正则分章，EPUB 按目录结构 |
| 阅读器 | 应用内阅读，记录进度（章节 + 位置） |
| 搜索 | 书名/作者/标签筛选，章节内全文搜索 |

### 支持格式

| 格式 | 分章方式 |
|------|---------|
| TXT | 正则匹配（`第X章`、`第X节`、`Chapter X` 等），用户可手动调整 |
| EPUB | 按 EPUB 内置目录结构 |

### 阅读状态

| 状态 | 说明 |
|------|------|
| `unread` | 刚导入，未开始 |
| `reading` | 阅读中，有进度记录 |
| `finished` | 已读完 |
| `dropped` | 弃读 |

### 标签体系

独立的 `novel_tag:` 注册表，与 URL/媒体标签互不影响。小说标签语义独立（如：言情、玄幻、完结、在读）。

## 存储设计

小说文本量大，不放 BuntDB。BuntDB 只存注册表（`novel:{id}`），章节内容按需从文件读取，不常驻内存。

```text
persist/
└── novels/
    └── {novel_id}/
        ├── meta.json          ← 元信息 + 阅读进度 + 章节目录
        ├── cover.jpg          ← 封面图
        └── chapters/
            ├── 001.txt        ← 解析后的章节纯文本
            ├── 002.txt
            └── ...
```
